scrcpy-f: avisos de terceiros
=============================

O scrcpy-f usa os componentes de terceiros listados abaixo. Cada um
continua sob a licença do próprio autor. Este arquivo existe para atender
aos avisos de atribuição exigidos por essas licenças.

O scrcpy-f em si é distribuído sob a GNU General Public License v3.0:
veja o arquivo LICENSE.


1. BIBLIOTECAS PYTHON (instaladas pelo requirements.txt)
--------------------------------------------------------

O núcleo do scrcpy-f (achar o celular, montar a linha de comando, subir e
derrubar a sessão) usa só a biblioteca padrão do Python, de propósito. O
pystray e o Pillow existem por causa do ícone da bandeja do Windows e dos
desenhos da janela; o pywinrt, por causa das notificações.

3. PROGRAMAS EXTERNOS
---------------------

scrcpy
  Apache License 2.0
  Copyright (C) 2018 Genymobile
  Copyright (C) 2018-2026 Romain Vimont
  https://github.com/Genymobile/scrcpy

  O scrcpy-f é um envelope em volta do scrcpy: ele chama o executável
  como programa externo. Nenhuma parte do scrcpy vai no código nem no
  pacote publicado. O botão "instalar" baixa o zip oficial direto do
  GitHub da Genymobile, na máquina de quem usa (ou a pessoa aponta a
  pasta de um scrcpy que já tem).

adb, Android Debug Bridge (Android SDK Platform Tools)
  Apache License 2.0
  Copyright (c) The Android Open Source Project
  https://developer.android.com/tools/adb

  Acompanha o pacote do scrcpy. Chamado como programa externo, também
  não é redistribuído.


4. COMPATIBILIDADE COM A GPLv3
------------------------------

A LGPLv3 do pystray pode ser usada junto de qualquer licença, inclusive a
GPLv3. A licença do Tcl/Tk e a MIT do pywinrt são permissivas. A MIT-CMU
do Pillow e a Apache License 2.0 (OpenSSL, scrcpy, adb) são compatíveis
com a GPL versão 3 (a Apache 2.0 não é compatível com a versão 2). A PSF
License 2 é compatível com a GPL desde o Python 2.2.

Nenhuma das dependências acima impede a distribuição do scrcpy-f sob a
GPLv3.
